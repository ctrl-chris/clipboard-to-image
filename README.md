# 🖼️ Quick Image Save Browser Extension

A rowser extension that automatically saves clipboard images to your downloads with one click. Perfect for quickly converting screenshots to image files!

<br>

## ✨ Features

- ⚡ **One-click saving** - Just press Ctrl+V and it automatically saves
- 🖼️ **Dual format support** - Save as PNG (transparent) or JPEG (white background)
- 📁 **Smart naming** - Automatic timestamp-based filenames
- 🎯 **No distractions** - Clean, minimal interface

# 🚀 Installation Guide

### Step 1: Download the Extension
Download the `Extension` folder from this repository to your computer.

### Step 2: Unzip Correctly (Important!)
If you downloaded a ZIP file:
- **Right-click** the ZIP file
- Select **"Extract All"** or **"Unzip"**
- Choose where to save the unzipped folder
- Make sure the folder contains these files:
  - `manifest.json`
  - `popup.html` 
  - `styles.css`
  - `popup.js`

### Step 3: Open Browser Extensions
- **Chrome**: Go to `chrome://extensions/`
- **Edge**: Go to `edge://extensions/`
- **Brave**: Go to `brave://extensions/`

### Step 4: Enable Developer Mode
Toggle the **"Developer mode"** switch in the top-right corner of the extensions page.

### Step 5: Load the Extension
1. Click the **"Load unpacked"** button
2. Navigate to and select the **unzipped `Extension` folder**
3. Click **"Select Folder"**

### Step 6: You're Done! 🎉
The extension icon will appear in your browser toolbar. You're ready to use it!

<br>

## 🎯 How to Use

### Basic Usage:
1. **Take a screenshot** or **copy an image** to your clipboard
2. **Click the extension icon** in your browser toolbar
3. **Press `Ctrl+V`** (or `Cmd+V` on Mac) anywhere in the popup
4. **That's it!** The image automatically saves to your Downloads folder

### Format Selection:
- **PNG**: Preserves transparency (perfect for screenshots)
- **JPEG**: White background, smaller file size (good for photos)

### File Naming:
Images are automatically named with timestamps:
- `image_2024-01-15_14-30-22.png`
- `image_2024-01-15_14-31-05.jpg`
